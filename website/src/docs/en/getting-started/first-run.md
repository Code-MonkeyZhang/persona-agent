---
title: First-Run Wizard
description: Complete initial setup in four steps and start your first chat
---

The first time you launch the app, a setup wizard appears automatically and walks you through initial configuration in minutes. There are four steps and every one of them can be skipped as needed.

## Step 1 Keys and Model

Pick a model provider, enter its API key, and click verify and save. Once verified, this provider becomes the default model source. You can also skip this step, but the agent cannot reply until you complete it later in [Model Access](/docs/getting-started/model-access).

## Step 2 Voice Service

Configure a MiniMax API key to unlock voice playback, preset voices, and voice cloning. This step is entirely optional, skip it if you do not need voice.

## Step 3 Agent Identity

Name your first agent and write its description, system prompt, and pick a voice. The system prompt defines its personality and behavior, and can be changed any time in the [agent editor](/docs/agents/create).

## Step 4 Meet the Three Abilities

The wizard closes with an introduction to MCP tools, agent skills, and Agent Apps, giving you the big picture of the extension system. Click Start Chatting to enter the main window.

## Replay the Wizard

To watch it again, open the general settings page and use the replay first-run wizard button. Replay mode can be closed at any time.
