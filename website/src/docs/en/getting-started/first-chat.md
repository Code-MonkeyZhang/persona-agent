title: Your First Chat
description: Send messages, inspect reasoning, stop and interject, switch models
---

With model access done, click the chat entry at the top of the session sidebar and start talking to the current agent.

## Sending Messages

Type in the input box at the bottom, press Enter to send, and Shift plus Enter for a new line. Replies stream in live as the agent generates them.

## Reasoning and Tool Calls

If the model supports reasoning, a collapsible thinking block appears above the reply, expandable to the full chain of thought. Tool invocations show up the same way, with parameters and raw results visible on expansion. Code blocks support collapsing and one-click copy.

## Stop and Interject

You can stop a reply at any moment, or simply type a new message while it is still generating. Interjections are queued and injected between the agent's steps without interrupting the current action.

## Switch Model and Working Directory On the Fly

The popover above the input box holds the model selector and the working directory selector. You can switch models mid-conversation or point the agent at a different directory.

## Copy and Unread

Any message can be copied. When you switch to another agent, avatars with new replies show an unread dot that clears once you return.

To go deeper on how sessions work, read [Context and Memory](/docs/agents/context-memory). To give your character a voice, see [Voice](/docs/voice/setup).
