---
title: Voice Service Setup
description: Configure the MiniMax voice service and pick a TTS model
---

Voice capabilities are powered by MiniMax. Once connected you can give agents voices and have replies spoken aloud.

## Configuration Steps

- Register on the MiniMax website and create an API key.
- Open settings and go to the voice service tab.
- Paste the key and click verify and save.

## Choosing a TTS Model

The voice parameters section offers eight TTS models. They trade off between naturalness and generation speed. Keep the default if unsure, you can switch any time.

## Where Voice Config Lives

Voice configuration is persisted separately in your local data directory, apart from model provider keys.

Once configured, head to [Preset Voices](/docs/voice/presets) to pick a voice for your character, or see [Voice Playback](/docs/voice/playback) for how to switch it on.
