## 安装

点击智能体栏底部的罗盘进入商城，切到应用标签页，搜索或浏览后点击安装。应用会下载到本机并注册，安装完成后手机屏的桌面立刻出现它的图标。番茄钟是典型的 AgentApp 示例。

![番茄钟](/docs-images/app-pomodoro.png)

## 打开与关闭手机屏

手机屏默认收起。点击顶部标题条右侧的开关把面板展开，再点一次收起，面板宽度可以拖拽调整。

## 使用应用

在手机屏桌面点击应用图标打开，应用以完整界面运行，顶部栏提供返回。按 Esc 也可以逐层退回桌面。

- 手动使用：直接在应用界面里操作。
- 对话使用：直接吩咐智能体去操作它，比如让它记一条待办，它会调用应用完成。

安装多个应用后的个性化排版见[排列与壁纸](/docs/agent-apps/personalize)。
