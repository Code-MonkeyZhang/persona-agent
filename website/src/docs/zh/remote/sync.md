## 同步是怎么工作的

- **首次连接**：设备拉取一份完整快照，得到主机数据的全量副本。
- **持续同步**：之后的每一次变化都以增量形式流向设备，实时对齐。
- **断线恢复**：断线期间积压的变更会在重连后按序补发，不丢内容。

## 数据本位

Persona Agent 没有云端服务。你的会话、角色、记忆、配置全部保存在你自己的主机上，其他设备只是远程视图。对外网络请求只有三类，模型供应商的 API、GitHub 上的商城与更新检查。应用没有任何遥测或统计上报。

## 本机存储一览

数据集中在用户数据目录下，包含数据库、配置、角色目录、技能、工具、附件、壁纸与日志等子目录。设置的通用页有存储路径卡片，六条路径都可以一键打开查看。

## 隐私要点

- 模型 Key 与授权凭据以文件形式存放在配置目录，请保管好自己的主机权限。
- 远程访问的隧道由你按需开关，关闭后没有任何入口暴露在公网。
- 想彻底清空，删除整个数据目录即可，应用会像初次安装一样重新初始化。
