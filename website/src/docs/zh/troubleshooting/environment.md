## Windows 需要 Git Bash

命令类内置工具在 Windows 上通过 Git Bash 提供终端环境。应用启动时会自动检测，设置的通用页环境卡片显示状态。

- 状态就绪则无需任何操作。
- 缺失时卡片提供下载链接，安装完成后回到应用重新检测。

## uv 运行时

社区自研的 MCP 工具多以 Python 编写，需要 uv 运行时来启动。环境卡片同样会检测。

- 缺失时可以一键下载安装，无需手动配置环境变量。
- 下载失败通常是网络问题，点击重试，或检查代理设置后重试。

## 日志开关

通用设置里有启用日志开关。排查问题时先把它打开，复现问题后到日志目录取文件，见[日志与诊断](/docs/troubleshooting/logs)。

环境正常但仍有异常时，前往[常见问题](/docs/troubleshooting/common)。
