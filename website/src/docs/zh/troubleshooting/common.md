## 智能体不回复

最常见的原因是模型 Key 没有配置或已失效。到设置的模型供应商页确认目标供应商带已配置标记，必要时重新验证，见[模型接入](/docs/getting-started/model-access)。

## Key 验证一直失败

- 确认 Key 没有多余的空格与换行。
- 确认 Key 未过期、未欠费、有对应模型的使用权限。
- 供应商服务波动时稍后再试一次。

## 语音没有声音

确认语音服务已配置且聊天页头的语音开关是打开状态，见[语音播报](/docs/voice/playback)。长回复会先总结再播报，稍有延迟属于正常。

## 工具调不了

- 确认工具已分配给当前角色，见[分配给角色](/docs/mcp-tools/assign)。
- 自研工具确认 uv 就绪，Windows 确认 Git Bash 就绪，见[环境问题](/docs/troubleshooting/environment)。
- OAuth 型工具长时间未用会授权过期，重新走一遍授权。

## 想换界面语言

设置的通用页里切换中文与 English，即时生效。

## 想重新看新手引导

设置的通用页有重看首启引导按钮，随时可进可退。

## 手机连不上主机

确认主机端隧道处于启动状态，公网地址没有变化。地址变了的话在设备管理里更新，见[设备管理](/docs/remote/devices)。
