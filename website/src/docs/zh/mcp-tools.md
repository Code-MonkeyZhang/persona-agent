## 什么是 MCP 工具

工具是智能体真正能执行的动作。读写文件、执行命令、抓取网页，这些都靠工具完成。Persona Agent 的工具体系基于 MCP 协议接入，因此能兼容庞大的社区工具生态。工具服务支持三种连接形态，本地进程方式最常见，工具作为子进程在本机启动；HTTP 方式直连一个在线工具服务；OAuth 方式用于连接需要账号授权的服务，首次使用走一遍授权流。应用自带一批常用工具开箱即用，MCP 工具是在此之上按需加装的部分，两者对智能体来说没有区别。

工具与技能是两种东西。技能是写给模型看的知识，改变它怎么想；工具是真实运行的能力，决定它能做什么。技能教会角色写周报的格式，工具让它真的能打开文件读写。

## 安装与授权

MCP 工具的安装、授权与卸载都在应用内完成。点击智能体栏底部的罗盘进入商城，切到工具标签页，选择需要的工具点击安装，应用会下载工具代码、写入连接配置并把它注册进全局工具池。商城里的工具服务覆盖日程、笔记、健康、音乐等场景，卡片示例见下图。

![滴答清单](/docs-images/tool-dida365.png) ![Notion](/docs-images/tool-notion.png) ![健康管家](/docs-images/tool-health.png)

工具装好后并不会自动给任何角色使用，需要到工具分配页为具体角色勾选，这是刻意设计，保证每个角色只接触你允许它接触的能力。需要账号的工具首次连接时会弹出授权流程，按页面指引登录并授权即可，授权凭据保存在本机，断线后应用会自动尝试重连，长时间失效时重新走一遍授权。社区自研工具多以 Python 编写，需要 uv 运行时，设置页的环境卡片会检测状态，缺失时可以一键下载安装；Windows 上命令类工具还需要 Git Bash，同样有检测与指引。到设置的已安装工具标签页，选中工具后在详情里可以卸载，悬停出现的按钮即是卸载入口。

## 分配给角色

工具的授权粒度是按角色控制的，同一个工具可以给 A 角色用而不给 B 角色。在会话侧栏点击工具导航项，中央区域切换为工具分配页，左右两栏结构。左栏把工具分成已分配与未分配两组，点击未分配组的工具把它加入当前角色，已分配组的工具可以随时移出，立即生效，右栏显示选中工具的详情与能力说明。分配状态会注入智能体的运行上下文，它每一步都知道自己当前有哪些工具可用，对话进行中调整分配，下一轮立即反映。

## 内置工具一览

应用自带七个内置工具，无需安装即可分配使用。

| 工具 | 能力 |
| ---- | ---- |
| read | 读取文件内容 |
| write | 写入文件 |
| edit | 对文件做局部修改 |
| bash | 执行终端命令 |
| bash-output | 读取命令的输出 |
| bash-kill | 终止运行中的命令 |
| webfetch | 抓取网页内容，让智能体阅读在线资料 |

命令类工具在工作目录里执行，目录在角色配置与输入框里都可以指定。另有两个面向陪伴体验的工具，智能体用它们自主切换立绘表情，这类工具不需要手动分配。
