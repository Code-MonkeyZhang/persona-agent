---
title: 上下文与记忆
description: 压缩、溢出保护与长期记忆的运作方式
---

每个智能体维护自己的上下文与记忆，应用用三层机制保证长对话不失控，你不需要手动清理。

## 上下文压缩

对话超过角色设定的压缩阈值后，应用在后台把较早的对话摘要成简短的总结追加进历史。原文永远不会被删除，只是不再完整塞进模型窗口。

## 溢出保护

即使压缩来不及完成，当未摘要内容估算出的 token 逼近模型窗口九成时，应用会从最老的完整一轮开始裁切，保证请求不会因为超长而失败。

## 长期记忆

每个角色有一个记忆整理节拍。到了设定的间隔，或者未处理的记忆条目积累到一定数量，智能体会把值得长期记住的内容整理成记忆文档，并在之后的常驻聊天里持续参考。你可以把它理解为角色自己的笔记本。

## 记忆存在哪里

记忆文件保存在本机数据目录该角色的专属文件夹里，和角色的配置放在一起，随[远程访问](/docs/remote/sync)的同步机制在其他设备上可用。

理解了记忆再看[形象定制](/docs/agents/appearance)，把角色的外表也配置起来。
