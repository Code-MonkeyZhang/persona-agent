## 远程访问

远程访问让你在手机或其他电脑上使用家里的 Persona Agent，而数据始终留在你自己的主机上。点击智能体栏底部的路由图标打开远程访问面板，点击启动，应用通过 Cloudflare 建立一条隧道，把本机服务映射到一个公网地址。隧道启动后会显示分配的公网地址，一键复制后在任何设备的浏览器里打开即可连接，这个地址在隧道关闭前持续有效。不需要远程时点击停止关闭隧道，公网地址随即失效，本机服务不再对外暴露，按需开关是最稳妥的使用习惯。

## 手机配对

隧道启动后，用手机扫码即可完成配对。远程访问面板里显示配对二维码，用手机浏览器或系统相机扫描，手机会直接连上你的主机，进入可用的设备列表。手机首次连上时会拉取一份完整的数据快照，包括你的角色、会话与配置，这个过程的长短取决于数据量，之后就只同步增量变化，速度很快。配对过一次的设备下次连接不需要再扫码，在设备清单里直接点选即可切换连接。

## 设备管理

配对过的设备集中在一个清单里管理。点击智能体栏底部的设备图标打开清单浮层，所有配对过的设备都在这里，点击条目即可切换连接的主机，底部入口进入完整管理页。在设备管理页里可以新建一个连接并手动录入主机地址，可以给常用的设备重命名，可以在主机换了网络或地址变更时修改连接地址，也可以删除设备。删除只影响这台设备自己的连接凭据、缓存与本地镜像数据，你主机上的任何数据都不会被动到，重新配对即可再次使用。

## 同步机制与数据本位

远程体验的背后是一条快照加变更流的同步机制。首次连接时，设备拉取一份完整快照，得到主机数据的全量副本，之后的每一次变化都以增量形式流向设备，实时对齐，断线期间积压的变更会在重连后按序补发，不丢内容。

Persona Agent 没有云端服务。你的会话、角色、记忆、配置全部保存在你自己的主机上，其他设备只是远程视图。对外网络请求只有三类，模型供应商的 API、GitHub 上的商城与更新检查，应用没有任何遥测或统计上报。数据集中在用户数据目录下，包含数据库、配置、角色目录、技能、工具、附件、壁纸与日志等子目录，设置的通用页有存储路径卡片，六条路径都可以一键打开查看。模型 Key 与授权凭据以文件形式存放在配置目录，请保管好自己的主机权限。远程访问的隧道由你按需开关，关闭后没有任何入口暴露在公网。想彻底清空，删除整个数据目录即可，应用会像初次安装一样重新初始化。
