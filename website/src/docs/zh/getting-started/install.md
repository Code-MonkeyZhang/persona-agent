## 下载应用

前往官网[下载页](/#download)，根据你的系统选择安装包。应用提供 macOS 与 Windows 两个平台的官方构建。

- macOS 提供 Apple Silicon 与 Intel 两种芯片的安装包，下载 dmg 文件后拖入应用程序目录即可。
- Windows 提供安装程序，运行后按向导完成安装。

## 首次打开的注意事项

macOS 首次启动如果提示无法验证开发者，在系统设置的隐私与安全性里选择仍要打开即可。Windows 如果弹出安全提示，选择仍要运行。

## 检查更新

应用的更新在设置里手动完成。打开左侧栏底部的设置入口，进入通用设置的版本与更新卡片，点击检查更新。发现新版本后依次点击下载更新、重启并安装，下载过程有进度条显示。应用不会在后台自动下载或安装任何版本，节奏完全由你控制。

遇到更新或安装问题时，参考[环境问题](/docs/troubleshooting/environment)与[常见问题](/docs/troubleshooting/common)。
