---
title: 首次启动引导
description: 四步向导完成初始配置并开始第一场对话
---

第一次启动应用时会自动弹出引导向导，带你在几分钟内完成初始配置。向导共四步，每一步都可以按需跳过。

## 第一步 密钥与模型

选择一家模型供应商，填入它的 API Key，点击验证并保存。验证通过后这家供应商会作为默认模型来源。也可以选择跳过配置，但跳过后智能体无法回复消息，之后需要在[模型接入](/docs/getting-started/model-access)补齐。

## 第二步 语音服务

配置 MiniMax 的 API Key 后，应用获得语音播报、预设音色和录音克隆三项能力。这一步完全可选，不需要语音可以直接跳过。

## 第三步 角色身份

给你的首个智能体起名字、写简介和系统提示词，再选一个音色。系统提示词决定了它的性格和行为方式，之后随时可以在[角色编辑](/docs/agents/create)里修改。

## 第四步 认识三种能力

向导最后介绍 MCP 工具、Agent 技能和 AgentApp 三个概念，帮你建立对扩展体系的整体认识。点击开始对话进入主界面。

## 重看引导

想再看一遍向导，到设置的通用页找到重看首启引导按钮即可，回放模式随时可以关闭退出。
