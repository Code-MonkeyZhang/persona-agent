Persona Agent 是一个开源的 Personal Agent 桌面应用。你在本地构建属于自己的 AI 角色，通过对话让它帮你处理事务，也可以接入技能、工具和应用扩展它的能力。所有数据都保存在你自己的电脑上。

## 五个核心概念

- **智能体**：你的 AI 角色。每个智能体有独立的性格设定、形象、模型配置和记忆，互相隔离。
- **会话**：与智能体的对话。每个智能体有一个常驻聊天会话，随时接着聊；也可以为具体任务另开会话。
- **技能**：写给智能体看的知识包，本质是一份说明文档。分配后智能体按文档内容调整自己的行为。
- **工具**：智能体真正能执行的动作，比如读写文件、跑命令、抓网页。基于 MCP 协议接入。
- **应用**：带自己界面的工具，安装后出现在应用内的手机屏里，智能体可以与它互动。

后三者的区别与安装方式，见 [AgentApp](/docs/agent-apps/concepts)、[MCP工具](/docs/mcp-tools/concepts) 与 [AgentSkill技能](/docs/skills/concepts) 各自的概念页。

## 主窗口布局

应用是单窗口结构，从左到右分为几块。

- 最左侧是智能体栏，一列头像就是你的所有角色，底部是商城、设备、远程访问和设置的入口。
- 中间是会话侧栏，上方是当前角色的聊天入口和工具、技能导航，下方是会话列表。
- 右侧主区域随导航切换，显示聊天、角色编辑、工具分配或技能分配页面。
- 最右侧可以展开一块手机屏，运行安装的 AgentApp。
