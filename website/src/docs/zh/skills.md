## 什么是技能

技能是一份写给智能体看的说明书。它的本质是一份结构化的 Markdown 文档，分配给角色后，全文会注入角色系统提示词的可用技能区块，让角色按文档约定的方式行事。分配完成的那一刻，角色的知识就更新了，无需重启或刷新。角色还被要求在对话中如实说明自己掌握的技能清单，运行过程中应用会把技能清单的任何变化告知角色，保持认知同步，你可以随时抽查它到底会什么。

技能适合用来教角色一套固定的工作流程，比如每天怎么整理日报；也可以注入领域知识，比如你的项目背景与术语表；还可以规定输出格式，比如周报必须按某个模板写。技能改变角色怎么想，工具决定它能做什么，需要实际读写文件或跑命令时，靠的是[工具](/docs/mcp-tools#什么是-mcp-工具)。

## 安装技能

技能从商城安装到本机的全局技能库。点击智能体栏底部的罗盘进入商城，切到技能标签页，浏览或搜索后点击安装，技能文件会下载到本机的全局技能目录，并记录来源信息。技能覆盖日记、天气、资讯等场景，卡片示例见下图。

![日记写作](/docs-images/skill-diary.svg) ![天气查询](/docs-images/skill-weather.svg)

已安装的技能会显示已安装标识，不会重复下载。每个技能就是一份文档，你可以先完整阅读它，确认内容符合预期再分配，技能详情面板提供全文阅读入口，以大卡片浮层展示，按 Esc 或点击遮罩关闭。到设置的已安装技能标签页，选中技能后在详情里可以卸载，卸载全局库里的技能会同时让所有角色的这份技能失效，动手前想清楚。

## 分配与生效

和工具一样，技能的分配粒度也是按角色控制的。在会话侧栏点击技能导航项，中央区域切换为技能分配页，左栏列出全局技能库，点击把技能加入当前角色，再次点击移出，右栏显示选中技能的详情。技能教会角色做事的方法，工具让它真正动手，给角色配好[默认工作空间](/docs/agents#默认工作空间)，再配上相应[工具](/docs/mcp-tools#分配给角色)，技能才能真正落地。
