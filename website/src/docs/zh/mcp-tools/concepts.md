---
title: 什么是 MCP 工具
description: 认识基于 MCP 协议的能力扩展
---

工具是智能体真正能执行的动作。读写文件、执行命令、抓取网页，这些都靠工具完成。Persona Agent 的工具体系基于 MCP 协议接入，因此能兼容庞大的社区工具生态。

## 连接方式

工具服务支持三种连接形态。

- 本地进程方式，工具作为子进程在本机启动，最常见。
- HTTP 方式，直连一个在线工具服务。
- OAuth 方式，连接需要账号授权的服务，首次使用走一遍授权流。

## 与内置工具的关系

应用自带一批常用工具开箱即用，见[内置工具一览](/docs/mcp-tools/builtin)。MCP 工具是在此之上按需加装的部分，两者对智能体来说没有区别。

## 与技能的区别

技能是写给模型看的知识，改变它怎么想；工具是真实运行的能力，决定它能做什么。技能教会角色写周报的格式，工具让它真的能打开文件读写。辨析见[产品概览](/docs/getting-started/intro)。

准备好就去[安装与授权](/docs/mcp-tools/install)。
