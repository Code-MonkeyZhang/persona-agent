## 安装

点击智能体栏底部的罗盘进入商城，切到工具标签页，选择需要的工具点击安装。应用会下载工具代码、写入连接配置并把它注册进全局工具池。

商城里的工具服务覆盖日程、笔记、健康、音乐等场景，卡片示例见下图。

![滴答清单](/docs-images/tool-dida365.png) ![Notion](/docs-images/tool-notion.png) ![健康管家](/docs-images/tool-health.png)

## 安装后要手动分配

工具装好后并不会自动给任何角色使用，需要到工具分配页为具体角色勾选，见[分配给角色](/docs/mcp-tools/assign)。这是刻意设计，保证每个角色只接触你允许它接触的能力。

## OAuth 授权

需要账号的工具首次连接时会弹出授权流程，按页面指引登录并授权即可。授权凭据保存在本机，断线后应用会自动尝试重连，长时间失效时重新走一遍授权。

## 运行时依赖

社区自研工具多以 Python 编写，需要 uv 运行时。设置页的环境卡片会检测状态，缺失时可以一键下载安装。Windows 上命令类工具还需要 Git Bash，同样有检测与指引，详见[环境问题](/docs/troubleshooting/environment)。

## 卸载

到设置的已安装工具标签页，选中工具后在详情里卸载，悬停出现的按钮即是卸载入口。
