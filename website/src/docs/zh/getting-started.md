## Persona 是什么？

Persona Agent 是一个集娱乐性和实用性于一身的开源的 Personal Agent 应用。你可以构建多个属于自己的 AI 角色，与它们聊天互动，也可以接入技能、工具和应用扩展它们的能力，让这些AI角色成为陪你左右的生活工作助手。

## 下载

前往官网[下载页](/#download)，根据你的系统选择安装包。应用提供 macOS 与 Windows 两个平台的官方构建。

| 平台    | 芯片          |
| ------- | ------------- |
| macOS   | Apple Silicon |
| macOS   | Intel         |
| Windows | 通用          |

macOS 打开 DMG 拖入 Applications 即可；Windows 运行 exe 安装程序按提示完成安装。

> Windows 安装包未签名，首次运行可能被 SmartScreen 拦截，提示「已保护你的电脑」。点击「更多信息」→「仍要运行」即可继续安装。

### 语音供应商

语音能力来自 MiniMax，到它的[开放平台](https://platform.minimaxi.com/)注册并创建 API Key，配置后应用获得语音播报、预设音色和录音克隆三项能力。
