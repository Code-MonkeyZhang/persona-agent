## 安装

点击智能体栏底部的罗盘进入商城，切到技能标签页，浏览或搜索后点击安装。技能文件会下载到本机的全局技能目录，并记录来源信息。技能覆盖日记、天气、资讯等场景，卡片示例见下图。

![日记写作](/docs-images/skill-diary.svg) ![天气查询](/docs-images/skill-weather.svg)

- 已安装的技能显示已安装标识，不会重复下载。
- 技能装进的是全局库，装好后还需要分配给具体角色才会生效，见[分配与生效](/docs/skills/assign)。

## 查看技能全文

每个技能就是一份文档，你可以完整阅读它，确认内容符合预期再分配。技能详情面板提供全文阅读入口，以大卡片浮层展示，Esc 或点击遮罩关闭。

## 卸载

到设置的已安装技能标签页，选中技能后在详情里卸载。卸载全局库里的技能会同时让所有角色的这份技能失效。
