---
title: 语音服务接入
description: 配置 MiniMax 语音服务并选择合成模型
---

应用的语音能力由 MiniMax 提供。接入后你可以给角色配置声音，让回复用语音播报出来。

## 配置步骤

- 到 MiniMax 官网注册并创建 API Key。
- 打开设置，进入语音服务标签页。
- 粘贴 Key，点击验证并保存。

## 选择合成模型

语音参数里可以选择 TTS 模型，共八款可选，不同模型在音色自然度与生成速度上各有侧重。不确定就保持默认，之后随时可以换。

## 语音配置的存放

语音相关配置独立保存在本机数据目录里，与模型供应商的 Key 分开管理。

配置完成后，前往[预设音色](/docs/voice/presets)给角色挑一个声音，或直接看[语音播报](/docs/voice/playback)怎么开。
